Module Handbook — CSE213

Course Overview

This module introduces client-side web development with HTML, CSS, and JavaScript. Students will build accessible, responsive applications from day one.

Prerequisites

  • CSE120 — Introduction to Programming
  • CSE125 — Networking & Web Technologies

Learning Outcomes

  1. Write valid, semantic HTML documents
  2. Apply CSS layout techniques including Flexbox and Grid
  3. Build interactive pages with vanilla JavaScript
