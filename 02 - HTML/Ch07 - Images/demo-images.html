🔍 DevTools In-Class Experiment: Observe CLS (Layout Shift)

  1. Open Chrome DevTools → Network tab.
  2. Set throttling to Slow 3G and check Disable cache.
  3. Right-click the first image → Inspect → delete the width and height attributes.
  4. Reload the page. Notice how paragraphs start at the top, and then get violently pushed down when the image loads! That is bad UX (Cumulative Layout Shift).
  5. Undo the change (Ctrl+Z in Elements) and reload. Notice how space is reserved instantly!
