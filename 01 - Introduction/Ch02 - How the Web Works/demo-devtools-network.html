HTTP Request / Response

Open DevTools → Network and hard-reload (Ctrl+Shift+R).

Click the first row (this HTML file) and explore the Headers and Response tabs.

What happens step-by-step

  1. Browser sends: GET /demo-devtools-network.html HTTP/1.1
  2. Server replies: 200 OK + Content-Type: text/html
  3. Browser parses the HTML → builds the DOM tree → renders pixels on screen

Key terms to remember

  • HTTP — the language browsers and servers speak to each other
  • GET — a request to READ a resource (most page loads)
  • POST — a request to SEND data (form submissions)
  • 200 — success. 404 — not found. 500 — server error
  • Content-Type — tells the browser what kind of data is arriving
  • DOM — the live tree structure the browser builds from your HTML
