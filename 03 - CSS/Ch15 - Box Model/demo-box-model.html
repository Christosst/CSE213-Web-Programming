Understanding the CSS Box Model

1. The Sizing Difference: content-box vs border-box

Both boxes below have width: 200px; padding: 20px; border: 6px solid;.

box-sizing: content-box (Default)

Content = 200px
+ 40px padding
+ 12px border
= 252px Total!

box-sizing: border-box (Modern Standard)

Total = 200px
Padding & border are accommodated inside the 200px!

2. Vertical Margin Collapse

Notice the distance between Block A and Block B. Block A has margin-bottom: 30px and Block B has margin-top: 30px. Rather than producing a 60px gap, the margins collapse to exactly 30px!

Block A (margin-bottom: 30px)
Block B (margin-top: 30px)
🔍 DevTools Inspection Tip:

Open DevTools (F12), click the element selector arrow, and hover over either box. Look at the bottom of the Styles panel: Chrome displays the interactive Box Model diagram with color-coded layers (Blue = Content, Green = Padding, Orange = Border, Peach = Margin)!
