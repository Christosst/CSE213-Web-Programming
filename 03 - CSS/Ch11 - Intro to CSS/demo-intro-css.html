Design Tokens (CSS Variables)

This card gets its border color from var(--brand-primary) and padding from var(--spacing-md). Change --brand-primary in :root to instantly re-theme the entire page!

Core CSS Selector Types

  • Element Selector: p { color: #333; } — targets all <p> tags.
  • Class Selector: .highlight { ... } — targets elements with class="highlight" (reusable!).
  • ID Selector: #header { ... } — targets the unique element with id="header" (use sparingly).
  • Descendant Selector: nav a { ... } — targets any <a> inside a <nav>.
