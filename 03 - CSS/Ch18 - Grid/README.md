# Chapter 18: Two-dimensional layout

Open `demo-grid.html` from the course index after running `npm start` at the repository root. Read the HTML first; then inspect the relevant CSS or JavaScript. The styling around the example is only for readability.

## Instructor demonstration (about 12–15 minutes)

1. Show line numbers and track sizes in the Grid overlay.
2. Resize the auto-fit gallery and explain minmax and fr.
3. Inspect area names and the narrow-screen template.

## Student exercise (about 20–22 minutes)

Build a named-area dashboard with an auto-fit gallery. Add a featured item that spans two tracks as a second step.
