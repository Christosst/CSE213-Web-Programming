## Live coding notes
1. Open DevTools → Toggle Device Toolbar → choose a narrow viewport.
2. Show the mobile-first stacked layout at 320px.
3. Widen to 768px — the media query fires, side-by-side layout appears.
4. Show the @container version — the card responds to its container width, not the viewport.
