Modern Web Typography & Scale

This heading and body copy use modern CSS typography patterns. Resize your browser window width and notice how the <h1> title scales smoothly between small mobile screens and widescreen displays without a single media query!

Font Stack Fallbacks

Our CSS declares --font-primary: 'Inter', system-ui, -apple-system, sans-serif;. If the user is offline or the custom web font is still downloading, the browser immediately falls back to high-quality native operating system fonts (San Francisco on macOS/iOS, Segoe UI on Windows, Roboto on Android).

Essential CSS Units for Students

  • rem (Root EM) — Relative to the root <html> font size (1rem = 16px by default). Best for general spacing, padding, and font-size.
  • em — Relative to the parent or current element's font-size. Great for margins that scale with the component's font size (like button padding).
  • ch — Equal to the width of the number 0. The industry gold standard for controlling reading line lengths.
  • clamp(min, preferred, max) — Creates a responsive value bounded between a lower and upper threshold.
