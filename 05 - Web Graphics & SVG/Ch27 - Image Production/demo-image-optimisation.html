Web Image Production: Defeating Layout Shifts (CLS)

❌ Anti-Pattern: Missing Dimensions

What's wrong: This image has NO width or height attributes. Before downloading, the browser reserves 0 pixels of vertical space. When pixels arrive, text leaps downward!

✅ Best Practice: Explicit Dimensions + Lazy Loading

What's fixed: The browser calculates aspect ratio (640 / 360) immediately, reserving space and eliminating Cumulative Layout Shift (CLS)!

✅ Pro Practice: Responsive Resolution Switching

Optimized bandwidth: Small mobile phones download the lightweight 400w file, saving cellular data and battery life!

⚡ Performance Checklist for Students:
  • Always include width and height attributes on <img>.
  • Always include loading="lazy" on below-the-fold images.
  • Never lazy-load your LCP Hero image (above the fold) — use fetchpriority="high" instead!
