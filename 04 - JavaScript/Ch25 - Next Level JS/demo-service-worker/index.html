How to Test Offline Mode in DevTools

  1. Open Chrome DevTools (F12 or Ctrl+Shift+I).
  2. Go to the Application tab → expand Service Workers on the left to see sw.js active and running.
  3. Go to the Network tab → change Throttling from No throttling to Offline.
  4. Press Ctrl+Shift+R (Hard Reload).
  5. Notice: The page still loads flawlessly, even without any internet connection, because the Service Worker served it from local Cache Storage!
