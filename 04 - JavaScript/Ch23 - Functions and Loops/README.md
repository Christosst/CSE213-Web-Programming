# Chapter 23: Functions, arrays and modules

Open `demo-arrays-modules/index.html` through `npm start` (ES modules need HTTP).

## Instructor demonstration (15 minutes)

1. Read the three objects in data.js.
2. Call filterProducts, productNames and totalPrice in utils.js; explain parameters and return values.
3. Compare totalWithLoop with reduce. Both give 18 for all products.
4. Select stationery: two names, total €6.00. Select books: one name, total €12.00.
5. Inspect import/export. The small display function previews chapter 24.

## Student exercise (22 minutes)

Add a product, then write a function that returns products below a chosen price. Prove the loop and reduce give the same total. Empty array should total zero.

## Show briefly

Closures and callback shorthand. Use normal named functions first. Sorting and complex rendering are extension work.
