# Chapter 24: A small task board

Open `demo-dom-events.html` from the course index after running `npm start` at the repository root. Read the HTML first; then inspect the relevant CSS or JavaScript. The styling around the example is only for readability.

## Instructor demonstration (about 12–15 minutes)

1. Create a task and inspect its new DOM nodes.
2. Complete and delete the task using keyboard-operable controls.
3. Explain why the one list listener handles newly created items.

## Student exercise (about 20–22 minutes)

Build a task board using createElement, textContent and event delegation. Enter <img src=x> and show that it remains text, not markup.
